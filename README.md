# SPYLT Animated Clone

Vercel-ready React + Vite clone of the referenced SPYLT GSAP animated experience.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The build bootstrap synchronizes the public SPYLT-GSAP source into the project before Vite builds it, so the repository stays lightweight while retaining the full animated experience and media assets.
